# Zona Morta

Jogo de sobrevivência zombie em pixel art, ao estilo State of Decay 2, com controlo tipo RTS. Comandas uma comunidade de sobreviventes, geres a base e destróis os corações da praga.

## Como jogar

Abre o `index.html` no browser. Funciona no telemóvel e no PC, sem instalar nada.

- **Selecionar:** toca num sobrevivente ou no cartão dele em baixo (no PC também dá para arrastar uma caixa).
- **Ordens:** toca no mapa para mover; num zombie para atacar; num carro, casa ou caixote para revistar; num sobrevivente com "!" para recrutar; num coração da praga para o atacar.
- **Botões:** Vasculhar, Guardar, Voltar, Parar, Armas, Tratar, Ficha.
- **Base:** 6 lotes para instalações (Horta, Enfermaria, Oficina, Torre de vigia, Dormitório, Gerador), muros e portões, rádio e arsenal.
- **PC:** WASD mexe a câmara, roda do rato faz zoom, 1–9 seleciona, espaço seleciona todos, V/G/H/B/P para vasculhar, guardar, voltar, base e pausa.

## Objetivo

Destrói os 4 corações da praga. Cuidado com a praga do sangue (só a Enfermaria a cura) e com as hordas que atacam a base de noite.
